# Python learning exercises

Standalone Python 3 exercises using the standard library. Run one script at a time and answer its prompts.

```sh
python challenge1.py
python gradecalc.py
python "string_pattern dectection.py"
```

## Exercise index

| Files | Topics |
| --- | --- |
| `challenge1.py` | Name and age input, printed text |
| `challenge2.py` – `challenge5.py` | Integer addition, parity, comparison, grading |
| `challenge6.py` – `challenge8.py` | Letter case, list membership, substring search |
| `challenge9.py` – `challenge10.py` | Number guessing and dictionary key lookup |
| `character_analyzer.py` | Validate and classify one character |
| `gradecalc.py` | Grade calculator with A/B/C/D thresholds of 90/80/70/40 |
| `membership_list.py` | Case-insensitive fruit lookup |
| `string_pattern dectection.py` | String pattern exercise |

`challenge5.py` uses a different grading scale from `gradecalc.py`; each is a separate exercise. Numeric exercises generally expect integer input. File names and existing editor settings are retained.
